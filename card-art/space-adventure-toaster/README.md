# Space Adventure Toaster

Four supplied images arranged as one outbound mission:

1. `GOODBYE, KITCHEN` - Earth departure
2. `THE CRUMB SEA` - lunar pass
3. `MARS: SETTING FOUR` - Mars approach
4. `RINGSIDE SERVICE` - Saturn arrival

The WebP files are optimized copies of the four newest source images supplied
in Downloads. The JSON files are the exact Requirement5 card treatments. Rarity
is intentionally absent from the specs so the normal server roll owns it.
